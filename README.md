# G's Garage

G's Garage is a single-page fan site I built for my web design class about *Forza Motorsport 3*. I wanted it to feel like an early-2000s racing magazine, so I used distressed lettering, red speed stripes, and road markings between sections.

## What's on the page

- **Dream Garage** features three cars I'd take out for a lap, from the Mine’s Skyline R32 to the Lamborghini Miura and Audi R10 TDI.
- **Circuit notes** highlight a few corners on the Nürburgring Nordschleife. Click the map to see the full layout.
- **Photo gallery** features burnout and drift shots. Click a photo to enlarge it, then select **Close** or press **Esc** to return.

## View it locally

Keep `index.html`, `style.css`, and the image files in the same folder, then open `index.html` in your browser. The layout adjusts for desktop and phone screens.
